# CommunityArena 6.0.0 preview

Paper 1.21.11 / Java 21+. One server plugin JAR.

See [installation, map generation, kit assumptions and performance limits](INSTALL-V6.md).

Eighteen biome arenas, an enclosed courtyard lobby, nine screenshot-reference presets, a lobby layout editor, ranked/casual duels, private settings, parties, operator practice targets, friends and real-record standings. Native chunk generation replaces the old global block builder; a bounded async prewarm prepares maps ahead of play. Historical records and original inventory backups remain intact.

Visible kit slots/counts follow the supplied screenshots. Hidden enchantments, potion metadata and container contents are documented inferences, not an official MCTiers export. Network ping is not spoofed or guaranteed to improve.

Native client visuals, live TPS and power-loss testing remain unverified. Use staging and retain a full backup. Community tier placements are never generated by practice matches.

Build: mvn -f arena/pom.xml clean verify.
