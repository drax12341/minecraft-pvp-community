# Independent tierlist redesign

One community owns every result. No imported ladders, provider switcher or server directory.

Palette: obsidian #080b12, blue steel #111827, mist #a1adc1, diamond #68d9ef, amethyst #aa8bff, trophy #f2c572. Tier bands each have a meaningful color. Type: Rajdhani for competition headings, Inter for readable controls. Left aligned, wide tier board, compact mode selection, persistent testing action.

The first draft's generic hero and provider table are replaced by the tier board as the primary visual. Kit artwork uses original pixel SVG geometry with dimensional shading. A separate overall leaderboard complements the five tier columns. No fake rankings fill the new community: empty tiers have purposeful artwork and a direct testing route. An explicitly labeled local preview can demonstrate populated states without entering published results.

Testing is part of the product: session availability, kit guides, request builder, cooldowns, result history, appeals and staff review. Public snapshots exclude Discord IDs and private appeal content. Static hosting displays the last published export; the bot/API provide the live operational system after activation.
