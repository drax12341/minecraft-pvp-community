# Competitive website design study

Reviewed 8 November 2026. Scope: **18 reference projects**, with different evidence levels. Six usable screenshot/concept images were downloaded and visually inspected. Public page content and information structure were reviewed where readable. No live browser session was available: the browser host and PC pipe failed. No claim is made that every site was rendered, that historical screenshots represent today’s UI, or that our own updated site passed visual browser QA.

This tierlist remains independent. Reference sites supply design lessons only; none supply players, rankings or partner branding.

## Critique of the previous iteration

- Player names at 10–12px were too small for the central task. Decorative headings were receiving more attention than players.
- Fifteen ungrouped kit tabs made specialist modes hard to discover.
- The arena heading and separate testing banner repeated the same message and pushed the tier board down.
- An unlabeled symbol rail duplicated the main navigation without helping a new player.
- Ten repeated empty-state illustrations exaggerated the lack of data.
- Testing cards could show the first closed region while another region was open. There was no direct session-region/status filter.
- Filters had no concise recovery when they produced no matches.

## Chosen design system

Palette: deep arena navy `#080b12`, competition surface `#111925`, structure `#2a3548`, readable muted text `#9aaac0`, diamond action `#7cdff2`, trophy gold `#edc878`. Silver, copper, blue and amethyst have defined tier/placement roles. Color is accompanied by text, not used as the only status indicator.

Typography: Rajdhani for competition headings/placement numerals, Inter for controls and data. Player names and controls increase in size; fine print remains secondary. Numeric columns use tabular figures. No full-screen animated effects.

Two layout directions were compared:

```text
A: Marketing first (rejected for the rankings route)
   Header
   Large scene + headline
   Separate testing banner
   Long kit strip
   Rankings far below

B: Competition workspace (selected)
   Labeled header
   Compact arena introduction + testing action
   Main / Sub / All + searchable kit picker
   Illustrated kit tabs
   Selected kit + context
   Search / Region / Board or List / Density | Testing availability
   Five-tier board or leaderboard            | Tier legend
   Latest placements
```

The cinematic artwork is retained as identity, not repeated as a second decorative campaign. The tier board and testing workflow determine the rest of the layout. Original shield/crest SVGs replace assorted decorative symbols in the tier headings. Reference images remain in an ignored local research folder and are not deployed.

## Implemented from the study

- Grouped main/submode navigation and a searchable kit picker, including Ctrl/Cmd+K.
- Integrated hero testing action and removal of the duplicate banner and icon rail.
- Selected-kit heading and better readable player rows, avatars, controls and metadata.
- Tier crests, top-placement numerals, comfortable/compact rows and consistent table alignment.
- Filter recovery, keyboard player search, explicit sample preview and more restrained empty states.
- Session region/status filters that prioritize an actual open session and preserve the in-progress request form.
- Public testing availability remains a timestamped export. No false live-state or fabricated competition activity.

## Verification boundary

Automated DOM interaction tests cover groups, picker search/selection, filter reset, density, keyboard search, session filtering and request-form preservation. Existing queue, cooldown and appeal tests remain required. SVG/XML and CSS parsing are checked. Actual desktop/mobile layout, zoom, long-name clipping and screen-reader output still need browser QA once the browser host is connected. Viewing reference screenshots does not verify our own rendered website.
